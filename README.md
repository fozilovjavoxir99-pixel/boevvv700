# Kiyim do'kon web-sayti

Bu loyiha oddiy static (statik) veb-sayt bo'lib, quyidagi funksiyalarni bajaradi:

- Kiyim mahsulotlarini qo'shish
- Narx ko'rsatish
- O'lchamlarni ko'rsatish
- Baho va sharhlarni ko'rsatish
- Rasm yuklash
- Mahsulotlarni brauzerda xotirada saqlash
- Mahsulotni o'chirish

## Ishga tushirish

1. `index.html` faylini brauzerda oching.
2. Formadan mahsulot qo'shing.
3. Ma'lumotlar brauzer xotirasida saqlanadi.

## GitHub Pages uchun

Agar saytni internetga joylamoqchi bo'lsangiz, repo-ni GitHub ga yuklang va `Settings` > `Pages` bo'limidan `Deploy from a branch` tanlang.

NFC kartaga ulash uchun sayt URL manzilini NFC tagga yozib qo'ysangiz bo'ladi.

## Eslatma

Bu yerda ma'lumotlar faqat lokal (brauzer) xotirasida saqlanadi. Agar ko'p foydalanuvchi uchun sayt kerak bo'lsa, backend (masalan, Supabase, Firebase yoki Node.js API) qo'shish lozim bo'ladi.
